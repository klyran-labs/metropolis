# ADR 0002: x402 / AP2 HTTP 402 Gated Agent Payments

## Status
Accepted

## Context
Autonomous agents consuming Web APIs need a standardized protocol to negotiate payment on demand without human intervention, pre-shared API keys, or centralized billing infrastructure.

## Decision
We adopt the x402 HTTP 402 Payment Required standard backed by EIP-712 structured data signing:
1. When an agent requests a protected API without payment, the server responds with HTTP 402 and challenge parameters (token, amount, agent, recipient, deadline, nonce).
2. The agent signs the typed `SpendRequest` EIP-712 payload with its private key.
3. The server or payment gateway relays the signed transaction to Monad's `AgentWalletGuard.sol`.
4. `AgentWalletGuard` validates the signature, queries `PolicyEngine.sol`, executes the payment, and logs the outcome.

## Consequences
- Clean separation between HTTP transport and onchain clearing.
- Eliminates API key leakage risks; agents sign only single scoped spend requests bounded by deadline and nonce.
